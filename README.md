# Ship-frame shape optimization data

Replication data for Isogeometric shape optimization of trimmed ship-frame connections using consistent stress sensitivities.

Download **OE_Ship_Frame_Data.zip** and unpack it. The archive README indexes the verification scripts, model inputs, and numerical records. The accompanying checksum identifies the exact archive.

The archive contains manufactured shells and open joints, literature optimization benchmarks, trace geometry checks, and ship-frame response and optimization records. Two searches from a common prepared design use 8 and 56 subsequent whole-frame evaluations. The straight-frame stationarity comparison and the first-feasible IGA search have distinct records. The paired finite element checks apply to the fixed reference curve.

The small examples can be reassembled and solved with the included scripts. The ship-frame checks verify saved numerical records. New full-frame analyses require the original ship CAD and compatible analysis software.
